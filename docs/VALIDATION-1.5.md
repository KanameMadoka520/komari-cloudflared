# 本地验证记录：1.5.0-fix1-cloudflared.1

验证日期：2026-09-16。全部验证在本机完成，没有使用 GitHub Actions。

- 前端：npm ci 与 TypeScript/Vite 生产构建成功；Docker 内再次从内嵌源码完整构建前端。
- 后端：全量 Go 测试与 go vet 通过；Agent、上报接口、路由、Tunnel、密钥存储、metricstore、服务生命周期、迁移和 OAuth 相关包的 race 检查通过。
- 额外回归：旧协议消息格式、v1 上报 UUID 冒用拒绝、Tunnel 管理鉴权、令牌加密/进程重启恢复、带 fix1/定制后缀的插件版本约束。
- 旧数据库：以 SQLite 在线 backup API 创建一致性副本，在无外网的 Docker 网络中完整演练时间格式转换与历史迁移；没有对生产库执行测试请求。
- 保留检查：节点、账号、会话、主题、Ping、告警、OAuth、通知提供者和剪贴板按字段比对；时间字段按实际时刻归一化。加密密钥逐字节一致，原会话继续通过鉴权。
- 历史查询：逐节点验证负载历史接口；原始数据库独立保留。新库历史采用上游每小时 P95 聚合，不将其描述为原始采样的无损副本。
- 协议联调：用副本中的既有 v1/v2 Token 验证 HTTP、WebSocket、在线状态、UUID 隔离、两种命令下发消息与重连。测试 Agent 只接收命令帧，不执行命令。
- 浏览器：Chromium 检查首页、后台仪表盘、Tunnel、流量报告、插件、主题市场、终端工作台，页面均可访问且无 JavaScript 运行异常。
- 媒体：隔离 Caddy 使用只读媒体目录，横竖屏视频、海报和头像均支持正常读取及 Range 响应。

上述测试不代表已向真实旧 Agent 添加其原本不具备的远程文件管理能力，也不代表远端网络故障下所有 Tunnel 场景均已实测。Cloudflared 进程恢复测试使用本地替身，避免与生产 Tunnel 竞争。
