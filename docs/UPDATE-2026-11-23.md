# Komari 1.6.2 等价更新

本地版本为 `1.6.2-cloudflared.1`。后端和前端以官方 1.6.2 为稳定版基线，同时吸收后端 `47460e7` 与前端 `f927bd4` 的终端与主题修复。完整核对范围见 [UPSTREAM_VERSIONS.json](../UPSTREAM_VERSIONS.json)。

- 网页终端可左右、上下分屏。刷新页面后，可在服务端保留期内恢复原会话。空闲 WebSocket 保活，关闭标签时按标签清理，并兼容旧 Agent 的关闭指令。
- 文件管理器支持向指定目录上传，修复框选后选择状态丢失。编辑工作台支持多终端，保留原有命令剪贴板和 xterm 设置。终端背景通过合并现有主题配置保存。
- 管理员日志记录操作者、对象和执行结果。每个终端会话聚合为一条记录，远程命令和 SQL 原文从审计详情中省去。
- 修复月底续费日期跨到下个月、GPU 温度小数丢失、WebSocket Agent 断开后残留 HTTP 在线标记和主题列表重绘。
- PWA 只预缓存入口资源，按需缓存带构建指纹的静态资源。保留自有的安装引导和面板布局。

11 月 23 日快照的整套流量账本迁移暂缓。现有终身上下行、计费校准、手动重置、断线及重启恢复继续使用自有账本和存储。该迁移需要独立核对旧计费周期、总流量手工录入和持久化基线。

在本地执行后端测试、vet、竞态检测、前端构建及浏览器回归。上线前使用隔离的生产数据库副本验证历史查询、登录会话、流量计数和重启恢复。备份及测试记录存放于宿主机私有审计目录。
