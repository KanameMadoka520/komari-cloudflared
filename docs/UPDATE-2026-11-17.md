## 用户可见变化

- 终端区分分配、就绪、临时断线和结束状态。浏览器短暂断线后沿用原 request_id 重连；单边断线不再主动断开另一边，保留五分钟恢复窗口。
- 等待 Agent 的提示放在通知中，避免混入终端文本。主动关闭标签结束会话，不反复重连。支持心跳回传的 Agent 显示端到端往返延迟；旧 Agent 不回传时不显示虚构延迟。
- 修改字体、终端选项或界面语言不重建终端连接，保留终端缓冲。默认关闭自动 EOL 转换，明确保存的设置继续生效。
- 日志可按类型筛选，搜索消息、IP 和 UUID，查看完整详情并复制。搜索有短延迟，过期请求会取消；切换每页条数重新查询并回到第一页。
- 正常静态资源和前端页面请求不再刷日志；API、健康检查和异常响应仍记录，继续隐藏查询参数中的凭据。
