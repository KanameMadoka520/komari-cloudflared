# 1.6.1 等价升级（2026-10-28）

官方基线：后端 96cf0f7（1.6.1），前端 797ca79（1.6.1）。本分支版本为 1.6.1-cloudflared.1。

吸收历史指标和 Ping 查询链路的批量读取、聚合、降采样与索引优化，独立扩大 Ping 入队容量；JavaScript 运行时迁移到 MoeJS，插件增加分类和 WebSocket 服务能力。前端吸收后台导航分组、插件搜索与快捷启停、弹窗配置、插件市场分类及加载动画。

## 保留与取舍

- 保留 cloudflared 加密配置与手动管理、Cloudflare Access OAuth、Caddy 媒体资源和既有站点美化。
- 保留终身累计流量、计费周期、手动总量校准、定时流量报告、负载警报、通知模板与时区、旧版 Agent、终端设置和命令剪贴板。
- 保留 Telegram/email/Bark/ServerChan/Javascript 等原有通知配置与适配层，不要求重新配置渠道。
- 采用官方 MoeJS 引擎，同时把此前修复的子进程输出排空与关闭顺序等价迁移，避免快速退出导致输出丢失。
- 保留通知流量阈值的负值保护和最新上报的 nil 检查。官方这次精简没有提供删除这些保护的充分理由。
- 保留 10 月 24 日本机已有的 Go/Node/Alpine/cloudflared 及依赖安全更新，升级不回退到官方较旧的依赖。
- 导航重组保留自定义入口；主题设置合并保存及通知配置请求竞态保护保留。

## 后续升级规则

先读取 UPSTREAM_VERSIONS.json，并对基线之后的变化做三方适配；不要整体覆盖 frontend/komari-web、Dockerfile 或数据目录。每次记录冲突取舍，再更新基线。

scripts/check-fork.sh 随本地检查运行，阻止关键自定义模块/菜单入口被删除及 workflow 被带入；实际行为还需通过流量、通知、终端相关测试和浏览器验证。它不能替代人工差异审查。

生产使用本机源码构建的 komari-cloudflared 固定版本镜像。不要切成官方镜像或 latest 标签；不引入自动拉取/覆盖源码流程，不使用 GitHub Actions。cloudflared 继续使用 --no-autoupdate。

数据、Token、密钥、美化配置留在生产数据卷，备份和部署审计留在仓库外。主题兼容改造不属于本次升级，未自动迁移美化或启用其他主题。
